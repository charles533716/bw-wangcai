# 场馆维护状态字段设计

## 目标

在总控后台“资源管理 → 场馆管理 → 场馆列表”的“切换场馆状态”弹窗中，当“设置场馆状态”选择“维护中”时，展示并保存维护日期、原因备注和客户端是否展示维护时间的配置。

## 交互设计

- 仅当状态为“维护中”时展示维护配置区域。
- 维护起始时间：日期选择器，必填，格式为 `YYYY-MM-DD`。
- 维护结束时间：日期选择器，必填，格式为 `YYYY-MM-DD`，不得早于维护起始日期；允许与起始日期相同。
- 原因备注：文本域，非必填，最多 50 个字符，并显示字数统计。
- 展示维护时间：单选项，必填，包含“展示”和“不展示”，默认选择“展示”。
- 状态切换为“启用”或“停用”时隐藏上述维护配置，不要求填写。
- 不实现参考截图中的引导前往场馆、引导自动跳转和自动跳转倒计时。

## 数据与日志

- 场馆 Mock 数据增加当前维护配置，包括起始日期、结束日期、原因备注和是否展示维护时间。
- 打开状态弹窗时，若场馆已有维护配置则回填；否则使用空日期、空备注和默认“展示”。
- 提交“维护中”状态后保存当前维护配置，并新增维护日志。
- 维护日志的维护起止时间和维护原因使用本次填写的数据。
- 切换为“启用”或“停用”不会删除已有维护日志；场馆保存过的维护配置保留，便于再次进入维护状态时回填。

## 校验和反馈

- 未填写起始日期或结束日期时阻止提交，并提示对应必填项。
- 结束日期早于起始日期时阻止提交并提示日期范围错误。
- 原因备注超过 50 个字符时阻止提交；输入框同时限制最大长度。
- 校验通过后沿用现有“场馆状态已更新”成功反馈。

## 影响范围

- `src/views/resources/venueManagement/VenueList.vue`：条件表单、回填、校验和提交。
- `src/views/resources/venueManagement/model.js`：维护配置默认值、迁移与日志字段。
- `scripts/check-venue-management.js`：新增维护日期校验、保存和日志联动检查。
- `docs/PROGRESS.md`、`docs/DECISIONS.md`：实施完成后记录结果。

不修改游戏列表、钱包列表、站点目录或其他资源管理功能。

## 验收标准

1. 选择启用或停用时不显示维护配置。
2. 选择维护中时完整显示四项维护配置。
3. 日期仅设置年月日，结束日期不得早于起始日期。
4. 成功提交后刷新页面仍能回填维护配置。
5. 维护日志正确显示填写的日期范围和原因。
6. 既有场馆授权、游戏授权和其他场馆管理检查保持通过。
