# 场馆状态与站点授权弹窗设计

日期：2026-08-06

## 目标

将总控后台“资源管理 → 场馆管理 → 场馆列表”中的“切换场馆状态”“授权”“取消授权”三个简单操作，调整为参考截图的可筛选、可批量选择、可校验弹窗，同时复用项目现有总站/站点 Mock 数据。

## 范围

- 仅修改场馆管理共享模型、场馆列表组件及对应验证脚本。
- 不修改原独立游戏列表。
- 不修改场馆管理的游戏列表、钱包列表和维护日志结构；仅保持状态切换为维护中时继续写入维护日志。
- 不重构全项目站点 Mock，也不修改财务管理真实业务页面。

## 站点数据来源

- 弹窗通过现有 `src/api/site/site.js` 的 `listSite()` 读取总站/站点 Mock。
- 使用返回记录的 `id`、`code`、`nameZn` 和 `status`。
- 场馆管理不维护第二份站点名称目录，避免站点新增或改名后数据漂移。
- 弹窗打开时重新读取站点列表；读取失败时保留弹窗关闭状态并提示“站点列表获取失败”。

## 场馆授权数据

- 场馆记录新增 `authorizedSiteCodes`，保存具体已授权站点 CODE。
- 场馆列表“授权数”由 `authorizedSiteCodes.length` 实时计算，不再直接加减 `authCount`。
- 本地场馆管理模型升级版本。旧数据加载时，以原 `authCount` 为数量，按现有站点 Mock 顺序生成初始授权关系，保证旧演示数量尽量不变。
- 每个授权关系包含账单模板结算费率配置状态；原型以 `billingRateConfiguredSiteCodes` 保存已配置站点 CODE。

## 切换场馆状态弹窗

- 标题：切换场馆状态。
- 展示场馆名称，格式为“中文名称 / CODE”。
- 展示“已设置账单模板：已配置数量 / 已授权站点数量”。
- 状态单选项：启用、维护中、停用。
- 如果已授权站点中存在未配置结算费率的站点，显示：
  - 红色提示：“该场馆在 N 个账单模板中未设置结算费率！”
  - 灰色说明：“请先前往财务管理-账单模板中，设置该场馆的结算费率。全部账单模板设置完成后，才可启用！”
- 存在缺失费率时，提交“启用”会被拦截并提示；维护中和停用允许提交。
- 状态实际变化后更新时间；切换为维护中时追加维护日志，重复提交当前状态不重复写日志。

## 授权弹窗

- 标题：“场馆授权 - 场馆中文名称”。
- 只展示尚未授权的站点。
- 筛选项：
  - 站点 ID/编号：匹配站点 `id` 或 `code`。
  - 站点名称：匹配 `nameZn`。
  - 站点 ID 范围：开始与结束 ID，可单边输入。
  - 数据库 ID：精确匹配站点 `id`。
- “筛选”应用条件，“重置”清空条件并恢复未授权站点全集。
- 支持“全部”与单站点复选；“全部”只作用于当前筛选结果。
- 未选择站点时不能确定授权。
- 确定后合并站点 CODE、去重、更新授权数并持久化。

## 取消授权弹窗

- 标题：“场馆取消授权 - 场馆中文名称”。
- 筛选和选择规则与授权弹窗一致。
- 只展示当前已授权站点。
- 确定后从授权关系及已配置账单模板关系中同时移除所选站点，并更新授权数。
- 未选择站点时不能确定取消授权。

## 组件边界

- `VenueList.vue`：负责三个弹窗的展示、筛选状态和用户操作。
- `model.js`：负责授权关系迁移、筛选、授权、取消授权、账单模板统计和启用校验等纯数据行为。
- 父页面继续负责统一持久化，不新增跨页面状态管理。

## 验证

- 模型脚本先新增失败断言，再实现：
  - 授权数来自具体站点关系。
  - 授权与取消授权去重且同步账单模板关系。
  - 四类站点筛选条件正确。
  - 缺少账单模板费率时不能启用。
  - 完整配置后允许启用。
- 静态断言核对三个弹窗标题、筛选字段、状态选项和警告文案。
- 浏览器验收三个弹窗的筛选、全选、提交、授权数变化和状态校验。
- 运行生产构建及现有场馆管理、客户端资源配置、权限和菜单回归脚本。
