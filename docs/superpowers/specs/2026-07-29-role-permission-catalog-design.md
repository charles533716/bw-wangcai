# 角色权限配置设计

## 目标

基于总站后台当前实际菜单、页面和业务按钮，建立统一权限目录，并用于角色新增、编辑、查看、复制、权限预览、菜单过滤和按钮控制。

## 权限模型

- 层级：一级菜单 -> 页面 -> 操作权限。
- 页面节点包含“查看”权限；操作节点仅包含页面实际存在的业务操作。
- 权限标识使用小写英文与冒号分隔，格式为 `模块:页面:操作`，全局唯一。
- 搜索、筛选、分页、刷新和重置查询条件不建立独立权限。
- 隐藏详情页归入对应列表页的“查看详情”等操作，避免重复菜单。
- 当前项目已有的 `v-hasPermi` 标识通过兼容映射关联到统一权限标识。

## 数据结构

建立独立权限目录模块，统一输出：

- 菜单与页面定义。
- 页面操作权限定义。
- 权限标识兼容映射。
- 预置角色及默认权限。
- 权限树构建、搜索、统计、校验和权限清单导出方法。

角色数据保存已选权限标识列表。超级管理员始终拥有全部权限且不可由普通管理员修改。

## 角色管理

角色列表字段：

- 角色名称
- 角色描述
- 用户数量
- 状态
- 创建时间
- 更新时间
- 操作：查看、编辑、复制、删除、启用/禁用

新增和编辑角色包含角色名称、角色描述、角色状态和权限配置。权限配置支持：

- 权限搜索并保留树形层级。
- 全选、取消全选、展开全部、收起全部。
- 父子节点联动、半选状态。
- 操作权限选中时自动包含页面“查看”。
- 取消页面“查看”时取消页面全部操作权限。
- 已选择权限数量统计。
- 编辑回显与保存。

## 权限预览

角色查看弹窗提供“应用此角色预览”。启用后：

- 使用 `localStorage` 保存当前预览角色。
- 左侧菜单按页面查看权限过滤。
- 页面路由无查看权限时跳转至 401 页面。
- 页面按钮通过现有 `v-hasPermi` 与兼容映射控制。
- 页面顶部展示当前预览角色及“退出权限预览”入口。

超级管理员预览拥有全部权限。

## 预置角色

- 超级管理员：全部权限，只读。
- 运营人员：运营、活动、内容和公告相关权限。
- 财务人员：充值、提现、资金、账变、审核和财务报表权限。
- 风控人员：会员风控、审核、风险记录和风控配置权限。
- 客服人员：会员、订单、申诉及客服相关查询处理权限。

## 验证

- 权限标识全局唯一。
- 所有可见菜单页面均有查看权限。
- 页面现有 `v-hasPermi` 标识均可映射。
- 预置角色引用的权限均存在。
- 权限树父子联动、搜索、回显、保存和预览可操作。
- 生产构建通过。
- 输出 Markdown 权限清单。
