## 已知问题与风险

- 本地预览经常因开发服务进程结束而无法访问；应先重启服务并确认 HTTP 200。
- 旧版 Node 环境构建可能需要 `NODE_OPTIONS=--openssl-legacy-provider`。
- README 中的项目路径和端口说明来自上游模板，部分内容已经过时。
- 当前工作区不是干净状态，客户端资源配置文件尚未提交；后续不得覆盖或回退。
- `ClientResourceConfig.vue` 体积较大，后续修改应保持范围集中，避免引入全局样式回归。
- 项目已有多项静态检查脚本；客户端资源配置新增两个模型 smoke 脚本，页面交互仍需构建和浏览器验收共同确认。
- GitHub Pages 使用 `/bw-wangcai/` 公共路径，普通生产构建不能直接替代 Pages 构建。
